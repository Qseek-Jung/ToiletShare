# 대똥단결 Android 실기기 QA 계획

- 대상: 로컬 빌드 (main `eae0017` = 1.1.0 + 보안 1·2단계 + 광고 개선), 업로드 키 서명 release APK
- 기기: Galaxy S24 Ultra (SM-S928N, Android 16), USB adb
- QA 빌드 전용 설정(커밋 안 함): `testMode: true`(테스트 광고만), `bannerSource: admob`(새 배너 검증), WebView 디버깅 ON

## 원칙
1. 실제 광고 노출/클릭 금지 → QA 빌드는 테스트 광고만.
2. 운영 DB 사용 → 운영자 계정만 사용
   - 일반: sales@blockgolf.com (네이버)
   - 관리자: qseek@naver.com (카카오)
3. 테스트로 만든 데이터(리뷰, 화장실)는 QA 종료 시 삭제하고, 크레딧 시작·종료값을 기록한다.
4. 판정은 화면 캡처, WebView DOM 조회(CDP), DB 기록(credit_logs 등)으로 교차 확인한다.
