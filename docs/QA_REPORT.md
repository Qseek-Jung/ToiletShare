## 개선점 (QA 관찰 기반, 우선순위순)

### 높음
1. **보안 3단계(RLS 잠금)**: 1.1.1 출시와 강제 업데이트 후 진행해야 한다. 그 전까지는 DB가 공개 키로 수정 가능한 상태다.
2. **푸시 발송 성공률 26%**: 관리자 통계 기준 알림 허용 234명 대비 발송 92건. 만료 토큰 정리와 실패 사유 로깅이 필요하다.
3. **콜드 스타트 약 8초**: 앱 실행부터 가까운 화장실 카드 표시까지이며, 지도 타일은 그 후 약 2초가 더 걸린다. 1.9MB 단일 JS 번들을 분리(관리자 화면 지연 로딩)하고 초기 데이터를 캐시하면 개선된다.
4. **AdMob 수익 수령 조건**: PIN 입력, 세금 정보 등록, 개발자 폰 테스트 기기 등록. QA 중 하단 배너가 두 번 실수로 탭됐다. 배너가 하단 메뉴·탭과 붙어 있어 오클릭 위험이 있으니 4~8dp 간격을 권장한다.

### 중간
5. **전면광고 빈도**: 홈 카드 탭, 길찾기, 종료 시마다 노출된다. 빈도 제한(예: 3분 1회)과 종료 광고 제거를 권장한다.
6. **관리자 화면 로딩 6~8초**: 회원 통계, 탈퇴 회원, 화장실 통계. 서버 집계 함수와 로딩 스켈레톤이 필요하다.
7. **관리자 모바일 표 레이아웃**: 가로 스크롤과 줄바꿈이 많다. 카드형 목록으로 전환을 권장한다.
8. **크레딧 조정 피드백**: 성공 토스트가 없고, 숫자 키보드가 확인 버튼을 가린다.
9. **광고 설정 화면**: Android 기기에서도 iOS 탭이 기본으로 열린다. `Android_Banner` 값이 비어 있다(코드는 기존 배너 ID로 대체).
10. **관리자 통계 계산 의심**: 평균 평점 0.0, 증가율 +100%.

### 낮음
11. **용어 혼용**: "+5 Credits", "(0cr)", "크레딧"이 섞여 있다.
12. **이용약관 버튼 문구**: 좌상단 "홈으로"가 실제 뒤로가기 동작(이전 화면)과 다르다.
13. **등급명 불일치**: "맨손"과 "손 (Lv.0)"이 혼용된다.
14. **등급 배지 깜빡임**: 리뷰 작성 직후 Lv.0으로 보였다가 Lv.1로 바뀐다.
15. **관리자 메뉴 제목 불일치**: 메뉴는 "회원 조회", 화면 제목은 "회원 통계"다.
16. **광고 실적 기간**: 종료일이 어제로 표시된다.
17. **운영 데이터 갱신**: DB 메시지 템플릿의 "크래딧" 표기와 버전 정책의 최신 버전 값(1.0.8)을 바꿔야 한다.
